# ООО «Лайн Консталт» — москитные сетки, Гомель

Статический сайт: index.html, setki.html, politika.html + assets.

## Лид-магниты на сайте
1. Калькулятор: тип, размер, количество, полотно, цвет → цена, скидка от 3 штук считается автоматически. Кнопка отправляет готовый расчёт в WhatsApp.
2. Бесплатный замер с образцами (заявка из формы или звонок).
3. Фото окна в WhatsApp: обещание ответить ценой в течение 15 минут.
